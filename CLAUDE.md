- mini app pour suggestion text chat 

context: 
pour une agence de tchating (only fans), je vais construire une outils pour suggestion de phrase lors d'une discussion. 

data: 
le client a déjà beaucoup de phrases disponible, qu'il utilise dans un contexte de discussion données. ex: relance (question), rapprochement (question sur hobby). 
le client n'a pas de classement sur ces contextes, juste la liste des questions. 

problématique: 
éviter redondance et gain temps de reflexion pour autre phrase. 


fonctionnalité : 
- enrichir la data exemple : user peut enrichir la base simplement en copie coller (et generation context des phrases de base)
- demander une suggestion  : user peut demander une suggestion à partir de context auto généré par app, pour il saisit le context 

éxigence: 
app légé à heberger sur vercel, ou render ou autres gratuit hebergement. 
llm to use, open router (ou autre free) pour démo, en switch claude au futur !
